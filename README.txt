ポケモン たのしい 3たく クイズ v3

【GitHub Pagesへのアップロード】
1. このフォルダの中身をGitHubのリポジトリへアップロードしてください。
2. index.html がいちばん上の階層にあることを確認してください。
3. Settings → Pages → Deploy from a branch → main → / (root) → Save
4. 公開されたURLをiPhoneのSafariで開き、「ホーム画面に追加」してください。

【ポイント】
・画像はアップロードされた一覧画像から、ポケモンのカード部分だけを切り出しています。
・画像と名前の組み合わせは、今回の採用リストを手動で確認した範囲に限定しています。
・問題は画像当てだけではなく、タイプ、しんか、しんかまえ、しんかするか、タイプなかまなどを混ぜています。
・BGMと効果音はブラウザ内で生成します。スタートボタンを押したあとに鳴ります。
・BGMとおとはホーム画面でON/OFFできます。
・UIと問題文は、未就学児向けに漢字を使わない方針です。
